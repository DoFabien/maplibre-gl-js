# Physical encoding benchmark fixtures

`props_u32_fpf_256.mlt` is copied unchanged from
`maplibre-tile-spec/test/synthetic/0x01`. It is generated by
`SyntheticMltGenerator` with `cfg().fastPFOR()`.

Benchmark setup scans the physical stream metadata and fails unless at least
one `FAST_PFOR` stream is present. The fixture name is not used as evidence of
its encoding.
